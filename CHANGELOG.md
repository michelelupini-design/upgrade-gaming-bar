# Changelog

## 0.2 — experimental source release, 23 November 2026

- Joystick search with three-character suggestions, platform scope and alphabetical browsing.
- Favorites, illustrated guide, centered navigation and arcade-button feedback.
- Keyed strings and language selector: initial Italian/English coverage, six partial locales with English fallback.
- Transparent full Q11 publisher lockup and original UpGrade artwork; platform-text fallback in the public source.
- Development preview isolated from production HOME, empty distributable catalog, documented legacy integration assumptions and local checks.
- Reference-device acceptance of microSD boot and representative launch/exit. Separate original startup scenes/random rotation and video-plane cleanup documented; root integration is not bundled.

Initial licensing: MIT code, CC BY 4.0 for the three listed original non-brand artwork files, OFL font and separate brand permission. No compiled release binary is bundled.
