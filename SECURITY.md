# Security and private data

Do not attach passwords, private keys, device images, full backups or unredacted network logs to public issues or pull requests. Game payloads, BIOS and vendor firmware are also excluded.

For a potential vulnerability, use GitHub private vulnerability reporting if enabled on the eventual repository. If no private reporting path is available, open a minimal issue asking for one without disclosing exploit steps, credentials or identifying device data. No unverified contact address is supplied here.

The preview creates no remote service. Any SSH/root maintenance on the reference device is a separate private installation and is not a feature granted by installing the launcher. Avoid adding external network access or new Android permissions without a concrete need and review.
