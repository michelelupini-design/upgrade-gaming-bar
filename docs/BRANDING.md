# Publisher, product and artwork

**Q¹¹ Space Otherfold Games** is the complete publisher brand. **UpGrade Gaming Bar** is the product/venue identity. The existing technical package name remains for integration compatibility and does not imply vendor endorsement.

The launcher uses `assets/theme/upgrade-arcade-v2.png` and the transparent horizontal `q11-arcade-horizontal-v1.png`. The publisher mark retains the rainbow Q superscript 11, cosmic doorway and complete SPACE / OTHERFOLD GAMES lettering. Header language text is omitted; language selection remains in Settings.

Project artwork was generated with supplied owner brand references. The control-panel illustration uses the owner's reference photo. Generated material is not represented as an exclusive-rights or trademark-clearance finding.

Original vendor logos, game characters, game screenshots and third-party platform wordmark assets are not included. The public UI uses platform text fallback; optional private platform images are separate.

The three startup scenes and waiting cue were separately integrated on the reference device. Their original vendor video is not redistributed. See STARTUP.md for the integration boundary.
